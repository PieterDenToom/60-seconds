# Word Game

A playful and colorful word game built with Alpine.js, featuring an interactive start screen where players can configure their game settings.

## Features

### Start Screen

- **Playful Design**: Colorful gradient backgrounds with floating animated shapes
- **Interactive Settings**:
  - Number of teams (2-8)
  - Total words (10-100, in increments of 5)
  - Round duration (30-300 seconds, in increments of 15)
- **Smooth Animations**: Hover effects, button animations, and entrance animations
- **Responsive Design**: Works on desktop, tablet, and mobile devices

### Game Settings

- **Team Count**: Choose between 2-8 teams
- **Word Count**: Select 10-100 words (increments of 5)
- **Round Duration**: Set 30-300 seconds per round (increments of 15)

## Technologies Used

- **Alpine.js**: Lightweight JavaScript framework for reactive components
- **CSS3**: Modern styling with gradients, animations, and responsive design
- **HTML5**: Semantic markup structure

## Getting Started

1. Clone or download the project files
2. Open `index.html` in your web browser
3. Configure your game settings on the start screen
4. Click "Start Game!" to begin (game screen is currently a placeholder)
